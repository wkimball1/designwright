# Shot Contract

Each scene/shot should be independently replaceable.

```text
shot_id:
scene_id:
narrative_purpose:
transcript_span:
planned_duration:
visual_need:
preferred_source_tier:
source_or_evidence_id:
motion_level:
text_overlay:
caption_constraints:
aspect_requirements:
generated_media_allowed:
capability_needed:
fallback:
acceptance_evidence:
unchanged_invariants:
```

## Source tiers

1. real evidence/source media;
2. real screen/product capture;
3. deterministic/programmatic graphic;
4. licensed stock/archive;
5. generated still;
6. generated video.

Generated media must never masquerade as documentary/source evidence.
