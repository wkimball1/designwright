# Tool Capability Request

Designwright requests capabilities; an external registry/router selects implementations.

For every request specify:

- capability;
- required quality;
- privacy class;
- license/commercial-use constraint;
- hardware/platform constraint;
- acceptable latency;
- preferred external marginal cost ($0 by default);
- allowed remote use;
- required evidence;
- paid-escalation condition.

Routing precedence:

`approved local/free -> approved free-tier external -> approved paid specialist`

A tool's popularity is not qualification evidence. Benchmark quality, reliability, privacy, license, and cost.
